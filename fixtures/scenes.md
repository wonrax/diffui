# iced baseline scenes

The parity contract for the port: every scene here was captured as
`<scene-id>.png` from the real iced app at e1a5697a through wgpu's Metal backend
at 2x. `scene_suite::every` shoots the same ids from the port. The port reproduces each scene's state and its
information, layout and flow. Colors, borders and spacing may differ where GPUI's
way is better.

Generated by `diffui capture --markdown` on the `gpui-baseline` stack
(`src/capture/scenes.rs`); edit there.

## Fixture

`fixtures/make-fixture.sh <dest>` builds the repo. Every scene runs on a fresh
copy at `.../acme/render-toolkit`, so the tab reads `acme/render-toolkit`. Fixture
names used in steps (see `<dest>/.jj/fixture-manifest`):

- `kitchen-sink`: "feat(render): rework the pipeline", one of every file kind
- `cache-bindings`: its child, the tip that's pushed
- `feature/render-pipeline`: bookmark one commit ahead of origin; `@` sits on it
- `feature/auth`: pushed, then rewritten, so ahead and behind at once
- `large-diff` / `data/regenerate`: whole-file rewrite of 20k lines
- `many-files`: 240 added files
- `long-description`, `empty-revision`, `no-description`: metadata oddities
- `conflicted`, `conflict/settings`, `conflict/octopus`: conflicted revisions
- `divergent/take-a`, `divergent/take-b`: one divergent change
- `merge-commit`: merge of fix/parser-crash into feature/auth
- `trunk-conflict` / `fix/changelog-note`: would conflict if rebased onto main
- `release/conflicted`: conflicted bookmark; `experiment/remote-only`: remote-only;
  `feature/deleted-locally`: tracked and deleted locally; tag `v0.1.0`

Times in the shots read relative to the capture date, since the fixture's dates
are fixed in March 2026.

## Known oddity: Han and emoji in code surfaces

In these shots Han characters and emoji in monospace surfaces (diff, source,
history) draw as tofu boxes, while kana draws and the UI font's fallback works
(see author names). This came through the app's own text path, with the machine's
fonts visible to it. Don't reproduce the boxes; the port should show the glyphs.

## Not capturable offscreen

Native NSMenu look and behavior (right-click, Fetch caret, revset caret, menu
bar), traffic lights, native title bar behavior and window zoom, NSOpenPanel,
real trackpad scrolling and momentum, the row glow's CoreAnimation pulse. These
need a later real-window pass. Menu scenes below show the same entries through
the app's non-macOS overlay. GitHub PR tabs need a real remote and `gh`, so they
have no scene; see src/toolbar.rs and core/src/github.rs for what differs.
